# Semi-Annual Product Sales Dashboard

## Overview

The **Semi-Annual Product Sales Dashboard** is a specialized Odoo application that provides a comprehensive analysis of product sales performance over the past six months. It displays insights for every product in your inventory, offering businesses a clear view of sales trends and metrics in a visually engaging format.

## Features

- **Sales Analysis**: Track and analyze product sales over the last six months.
- **Visual Dashboards**: Interactive charts and graphs for better insights.
- **Performance Metrics**: Compare sales trends and forecast future performance.
- **User-Friendly Interface**: Intuitive UI for easy navigation and data interpretation.
- **Odoo Integration**: Fully compatible with Odoo’s reporting and analytics modules.

## Demo
To see the Semi-Annual Product Sales Dashboard in action,follow these steps:
1. Navigate to the Sales Dashboard module in Odoo.
2. Select the desired time frame for sales analysis.
3. View interactive charts and performance indicators.
4. Generate reports and insights for strategic decision-making.
